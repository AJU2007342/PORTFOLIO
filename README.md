# Ajutesh Boddeti — Personal Portfolio 🌐

A personal portfolio website built from scratch using vanilla HTML and CSS, styled with the **Carbon Amber** dark theme.

## 🔗 Live Demo
👉 [View Live](https://aju2007342.github.io/PORTFOLIO/)

## 🛠️ Built With
- HTML5
- CSS3
- Google Fonts
- Vs Code
## 📄 Sections
| Section | Description |
|---|---|
| **Hero** | Name, open to work badge, role, and CTA buttons |
| **Projects** | Cards for all projects with live links |
| **Skills** | Frontend, Backend, and Tools in 3-column layout |
| **About Me** | Bio + info card with university and status |
| **Contact** | Email, GitHub, and LinkedIn buttons |
| **Footer** | Name and university |

## 🎨 Design
- **Theme:** Carbon Amber — dark charcoal base with warm amber accents
- **Base:** `#0C0C0A` · **Surface:** `#161614` · **Accent:** `#D97706`
- Smooth scroll, hover animations, responsive layout
